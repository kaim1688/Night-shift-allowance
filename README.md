# 夜點費填表器 v0.1.6

純靜態網頁，班表及名冊僅在瀏覽器處理，不需要伺服器API。

Excel保留人員彙總、逐日明細，另為每位勾選人員產生一張A4直向請領表工作表，姓名及主管簽章欄留白；保留員工代號前導0與逐日替班設定。每頁19筆，超過則在同一工作表續頁。網頁也可列印另存PDF。

此發布包不內建人員資料。開啟後先選擇獨立保存的「私人名冊_請勿上傳GitHub.json」（保留售票領班設定），再選擇每月班表。
也可匯入人員基本資料.xlsx，前三欄為姓名、職稱、員工代號；第四欄選填ticket表示售票領班。代號使用7碼文字，保留前導0。Excel若沒有職務班別，請核對逐日替班設定。

此資料夾對應獨立儲存庫kaim1688/Night-shift-allowance。不要將本機原始資料夾或私人名冊一起提交。
GitHub Pages使用main分支的根目錄發布，更新main後會自動部署。
正式網址：https://kaim1688.github.io/Night-shift-allowance/ 。不影響其他專案網站。
