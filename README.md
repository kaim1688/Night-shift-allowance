# 夜點費填表器 v0.1.1

純靜態網頁，班表及名冊僅在瀏覽器處理，不需要伺服器API。

此發布包不內建人員資料。開啟後先選擇獨立保存的「私人名冊_請勿上傳GitHub.json」（保留售票領班設定），再選擇每月班表。
也可匯入人員基本資料.xlsx，前三欄為姓名、職稱、員工代號；第四欄選填ticket表示售票領班。代號使用7碼文字，保留前導0。Excel若沒有職務班別，請核對逐日替班設定。

請只將此資料夾推送到**新的獨立儲存庫**，不要覆蓋既有專案，也不要將本機原始資料夾一起提交。
在GitHub儲存庫 Settings → Pages 選擇 GitHub Actions，手動執行 Deploy Pages 工作流程即可。
尚未設定正式網址，也沒有修改任何已部署的網站。
